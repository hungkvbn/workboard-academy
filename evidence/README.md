# Bằng chứng học tập

Tạo thư mục `week-01`, `week-02`... cho nhật ký, kết quả test, ảnh/video hoặc đường dẫn PR. Có thể dùng một tài liệu liên kết tới Git repository thay vì chép mã nhiều lần.

Mỗi bằng chứng cần gắn với lab và acceptance check cụ thể. Không lưu secrets, mật khẩu thật hoặc thông tin người dùng thật. Ghi rõ dữ liệu mô phỏng, máy/OS đã test và phần chưa test.
